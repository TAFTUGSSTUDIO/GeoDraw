# GeoDraw! 🎨🗺️

**GeoDraw!** is a minimalist urban art generator that transforms real-world map data into clean, high-quality vector-style masterpieces. Designed for designers, cartographers, and city-lovers.

## ✨ Key Features
- **Aviation Mode:** Specialized styling for airports, featuring solid tarmac-grey runways and caution-yellow taxiways.
- **Smart Pathing:** Automatic "Dot-dot-dot" (. . .) styling for pedestrian walkways and dashed lines for off-road tracks.
- **Eye-Altitude Tracking:** Real-time altitude calculation (ft/mi) to help you find the perfect scale for your art.
- **Hybrid Stability Logic:** Built-in safeguards that warn you when an area is too dense, allowing for stable generation up to a 2.5-mile diameter.
- **One-Click Export:** High-resolution PNG downloading for instant use in frames or digital projects.

## 🚀 How to Use
1. **Navigate:** Move the map to your favorite city or airport.
2. **Scale:** Use the "Eye Alt" display to find your preferred height.
3. **Customize:** Use the toggle menu to show/hide buildings, roads, or rails.
4. **Generate:** Hit "GENERATE MAP" to draw the vector lines.
5. **Save:** Click "DOWNLOAD PNG" to save your creation!

## 🛠️ Built With
- Leaflet.js (Map Engine)
- Overpass API (OpenStreetMap Data)
- OSMtoGeoJSON (Data Translation)
